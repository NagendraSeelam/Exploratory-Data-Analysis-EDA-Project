# Exploratory Data Analysis Report

## Project Title
Exploratory Data Analysis (EDA) Project

## Dataset
Iris Dataset

## Analysis Performed

### Statistical Summary
Used describe() to analyze:
- Mean
- Median
- Standard Deviation
- Minimum and Maximum Values

### Correlation Analysis
Studied relationships between variables using a correlation matrix.

### Visualizations
1. Feature Distribution Histogram
2. Correlation Heatmap

## Key Findings
- Petal length and petal width show strong positive correlation.
- Sepal measurements show moderate correlation.
- Dataset contains consistent numerical observations.

## Conclusion
EDA helps identify patterns, relationships, and trends before building machine learning models.
